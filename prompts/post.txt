Конец образца.

Если в источниках 3 и более самостоятельных аспектов темы - ОБЯЗАТЕЛЬНО серия из 2-3 постов. Один пост - только для узкой темы с одним аспектом. Каждый пост - не более 3000 символов.

- media_suggestions: массив детальных промптов для генерации изображений -
  строго по одному для каждого поста серии (для одного поста - один элемент).
  Каждый промпт - это развернутое ТЗ на английском языке, 40-80 слов:
  субъект и действие, окружение, тип освещения, стиль (фотореализм,
  иллюстрация, 3D-рендер), композиция кадра и ракурс, цветовая палитра,
  настроение сцены. Только сам промпт, без пояснений и кавычек.
  Ключ JSON - именно media_suggestions.
- Абзацы: 1-3 предложения, между абзацами обязательно две новые строки. Простыни текста запрещены.
- Структура каждого поста должна быть РАЗНОЙ - не копируй схему образца буквально.
- Чередуй форматы: тезисы с эмодзи-маркерами, сплошной текст с подзаголовками, короткий
  плотный пост без списков, разбор по шагам, вопрос-ответ или дилемма.
- Число пунктов - от двух до четырех, иногда обойдись вообще без списка.
- Финал чередуй: вопрос к аудитории, тезис-вывод или призыв поделиться мнением.
