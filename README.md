# Topic Search Bot

Telegram-бот для поиска актуальной информации в интернете и генерации постов для Telegram-канала. От темы до опубликованного поста — одна кнопка.

## Что умеет

- **Подборка тем** по запросу: текст, голосовое (Vosk), фото/видео/документ, ссылка (Tavily Extract + yt-dlp для видео)
- **Новостные посты** в заданном стиле канала: строгий эталон подачи + ротация структур (тезисы, сплошной текст, разбор по шагам, вопрос-ответ)
- **Серии** из 2-3 постов для широких тем, склейка коротких хвостов, заголовки серий срезаются при публикации
- **Кнопки под каждым постом**: Ещё вариант / Короче / Без эмодзи / Опубликовать — каждая вариация получает свою клавиатуру
- **Публикация в канал** одной кнопкой: текст или медиагруппа с подписью, хештеги сохраняются
- **Детальные промпты для генерации изображений** (40-80 слов, EN) к каждому посту серии
- **Двуязычный поиск**: запрос автоматически расширяется английской версией — охват RU + EN интернета
- **Новостной сценарий**: триггерные слова переключают поиск на свежие новости (не старше 7 дней)

## Архитектура

- **aiogram 3** — Telegram-слой, FSM, reply-панель команд
- **Tavily** — нейросетевой поиск: семантический ранкинг, score-фильтр, topic news/general, extract для ссылок
- **Gemini** — генерация: принудительный JSON (response_schema), цепочка из 6 моделей, ротация двух API-ключей
- **SQLite** (aiosqlite, WAL) — пользователи, посты, счётчики квот, kv-хранилище
- **yt-dlp** — метаданные для ссылок на видео; **Vosk** — транскрипция голосовых
- **aiohttp** — healthcheck для watchdog

### Поток запроса

    /search → перевод запроса → Tavily → подборка тем (кнопки)
    → выбор темы → пост(ы) → кнопки вариаций → публикация в канал

Перевод и Tavily последовательны; guard релевантности и генерация поста идут параллельно (asyncio.gather).

## Быстрый старт

Требования: Docker и docker-compose (v2).

    git clone https://github.com/ArgentumSea/topic-search-bot.git
    cd topic-search-bot
    cp .env.example .env   # заполнить значения
    docker-compose up -d --build

Healthcheck: `curl http://localhost:8080/health` → ok

## Конфигурация (.env)

| Переменная | Назначение |
|---|---|
| BOT_TOKEN | токен от @BotFather |
| ADMIN_IDS | Telegram ID админов (JSON-список) |
| CHANNEL_ID | ID канала для публикации (или привязка через /channel) |
| GEMINI_API_KEY | ключ Google AI Studio, проект 1 |
| GEMINI_API_KEY_2 | второй ключ: другой проект = отдельный пул квот |
| LLM_MODELS | цепочка моделей (JSON-список, порядок = приоритет) |
| TAVILY_API_KEY | ключ Tavily (1000 кредитов/мес на free tier) |
| TAVILY_MAX_RESULTS | число источников (10) |
| TAVILY_MIN_SCORE | порог релевантности (0.4) |
| TAVILY_MONTHLY_BUDGET, TAVILY_RESET_DAY | бюджет кредитов и день сброса счётчика |

## Команды

- /start — приветствие + панель кнопок
- /search — подборка актуальных тем (текст, файл или ссылка)
- /topic — пост по готовой теме
- /last — последние посты с кнопками показа
- /channel — привязка канала для публикации
- /stat, /admin — статистика и управление (админы)
- /cancel — отмена

Без команды бот молчит: текст/файл вне сценария игнорируется — кредиты не тратятся.

## Квоты и устойчивость

- **Gemini**: полный перебор цепочки; ключ блокируется на 24 ч только по дневной капе (PerDay 429), затем переключение на второй ключ
- **Tavily**: локальный счётчик кредитов; при иссякании — уведомление всем и режим «без актуализации», при восстановлении — рассылка
- **Watchdog**: проверка /health каждые 5 минут; при падении — снимок диагностики в data/watchdog_last.log, рестарт, уведомление админу
- **Бэкапы**: ежедневно в 04:00 дамп SQLite в data/backups, ротация 30 копий
- Сообщения старше команды игнорируются (защита от накопившейся очереди)

## Структура проекта

    bot/
      main.py            — сборка приложения, роутеры, healthcheck
      config.py          — настройки (pydantic-settings)
      db.py              — SQLite: пользователи, посты, kv
      quota.py           — учёт квоты Tavily и рассылки
      handlers/          — команды, пайплайны, кнопки, файлы, админка
      services/          — llm (ротация ключей), search, posting, query_expand
    prompts/             — системные промпты (стиль канала кастомизируется здесь)
    deploy/              — watchdog.sh, backup.sh
    Dockerfile, docker-compose.yml

## Кастомизация стиля

Стиль постов задаётся в `prompts/post.txt`: эталон подачи, правила абзацев, ротация форматов, требования к media_suggestions. Подборка тем — `prompts/topics.txt`. После правки промпта нужна пересборка образа.

## Ограничения free tier

Поиск и генерация рассчитаны на бесплатные квоты Tavily и Google AI Studio. В часы пик Gemini может отвечать очередями по 30-60 с — это ограничение провайдера; бот корректно перебирает модели и ключи.
